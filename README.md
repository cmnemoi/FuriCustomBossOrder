# Furi Custom Boss Order

A mod for **Furi** that adds two new boss order modes for speedrun mode:

- **Reverse**: bosses are fought in reverse order
- **Random**: boss order is shuffled randomly

![demo](demo.webp)

Both modes are available with **Rider** and **Onnamusha**.

This mod has been tested with the latest version of **Furi**. Use it at your own risk.

## Installation

New : Use the [Furi Mod Manager](https://github.com/cmnemoi/FuriModManager)
